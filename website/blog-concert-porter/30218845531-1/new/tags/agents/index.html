A Weekend MCP-AQL Adapter for MakerPerks

A friend of mine built MakerPerks, a curated directory of builder perks: free credits, discounts, and programs for startups, students, open source maintainers, and indie developers. I saw it after we hung out one evening and thought it wanted an MCP server in front of it, so agents could query it directly. I used MCP-AQL to build one. It took a weekend, and most of that ran in the background while I did other things.
